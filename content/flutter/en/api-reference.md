# API Reference

## Runtime API (`sileo`)

The imperative controller class `SileoController` (exposed as the global singleton `sileo`) manages the notification queue.

### `sileo.show(options)`
Launches a toast using the explicit `type` in options, defaulting to `info`. Returns the toast's unique `id` (string).

### `sileo.success(options)`
Launches a success toast.

### `sileo.error(options)`
Launches an error toast.

### `sileo.warning(options)`
Launches a warning toast.

### `sileo.info(options)`
Launches an info toast.

### `sileo.action(options)`
Launches an action toast. Usually paired with a `button:` parameter in options.

### `sileo.loading(options)`
Launches a loading indicator toast. Automatically defaults to `sticky: true`.

### `sileo.promise<T>(futureOrFn, options)`
Launches a loading toast, executes and awaits the async `Future<T>`, and resolves/replaces it with success/action or error options when it settles.

*   `futureOrFn` accepts a `Future<T> Function()` (lazy generator) or a raw `Future<T>`.
*   Returns the original future's result or propagates its error.

### `sileo.dismiss(id)`
Dismisses the newest active toast matching `id`. If no `id` is passed, dismisses all active toasts.

### `sileo.clear(position)`
Instantly clears all toasts, or those matching the given `SileoPosition`, without showing exit animations.

### `sileo.configure(options)`
Applies global default settings merged into all future notifications.

## `SileoOptions`

Configuration payload passed to `sileo` invocations.

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `id` | `String?` | Autogenerated | Stable ID. Reusing an active ID replaces the toast in-place, resetting its duration. |
| `title` | `String?` | — | Primary header text. |
| `description` | `dynamic` | — | Body content. Can be a `String` or any custom `Widget`. |
| `type` | `SileoState?` | `info` | State used by `show()`. |
| `position` | `SileoPosition?` | Viewport default | Align position of this specific toast. |
| `duration` | `Duration?` | `6000` ms | Auto-dismiss countdown. Ignored if `sticky: true`. |
| `sticky` | `bool` | `false` | If true, remains on screen indefinitely until dismissed manually. |
| `icon` | `Widget?` | State default | Override icon inside the left badge. |
| `styles` | `SileoStyles?` | — | Custom text styles and decorations. |
| `fill` | `Color?` | Theme default | bespoke background color for this specific toast. |
| `roundness` | `double?` | `16.0` | Corner border radius in pixels. |
| `autopilot` | `dynamic` | `true` | Boolean or custom timings map `{expand: Duration, collapse: Duration}`. |
| `swipeToDismiss` | `bool` | `true` | If true, enables vertical swipe gestures to dismiss. |
| `button` | `SileoButton?` | — | Configuration for the primary action button. |
| `groupKey` | `String?` | `"__default__"` | Logical bucket key for grouping notifications. |
| `hooks` | `SileoLifecycleHooks?` | — | Event callbacks for lifecycle changes. |

## `SileoButton`

```dart
class SileoButton {
  const SileoButton({
    required this.title,
    this.onClick,
  });

  final String title;
  final VoidCallback? onClick;
}
```

## `SileoStyles`

```dart
class SileoStyles {
  const SileoStyles({
    this.titleStyle,
    this.descriptionStyle,
    this.badgeDecoration,
    this.buttonStyle,
    this.toastDecoration,
  });

  final TextStyle? titleStyle;
  final TextStyle? descriptionStyle;
  final BoxDecoration? badgeDecoration;
  final ButtonStyle? buttonStyle;
  final BoxDecoration? toastDecoration;
}
```

## `SileoLifecycleHooks`

```dart
class SileoLifecycleHooks {
  const SileoLifecycleHooks({
    this.onShow,
    this.onExpand,
    this.onCollapse,
    this.onDismiss,
  });

  final void Function(SileoLifecycleContext)? onShow;
  final void Function(SileoLifecycleContext)? onExpand;
  final void Function(SileoLifecycleContext)? onCollapse;
  final void Function(SileoLifecycleContext)? onDismiss;
}
```

## `Toaster` Parameters

Viewport widget mounted in your widget tree.

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `position` | `SileoPosition` | `topRight` | Default viewport position. |
| `offset` | `dynamic` | — | Custom viewport edge offsets (double, num, or `SileoOffsetConfig`). |
| `options` | `SileoOptions?` | — | Base default options merged into all viewport toasts. |
| `theme` | `SileoTheme` | `system` resolved | Color theme (`light`, `dark`, `system`, `custom`, `colored`). |
| `colors` | `SileoColors?` | — | BESPOKE color overrides for all states. |
| `grouping` | `bool` | `false` | If true, collapses bursts into a summary card. |
| `groupThreshold` | `int` | `4` | Number of notifications before grouping triggers. |
| `ariaLive` | `SileoAriaLive` | `polite` | Accessibility semantics configuration. |
